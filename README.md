# 📄 Formulário com HTTP

Projeto de formulário HTML integrado a um servidor HTTP com Node.js.

## 🚀 Tecnologias

-   Node.js
-   HTTP (módulo nativo)
-   HTML

## 🎯 Funcionalidades

-   Envio de dados via formulário
-   Comunicação cliente-servidor
-   Processamento de requisições HTTP

## ▶️ Como executar

node server.js

Acesse: http://localhost:3000
